3 分鐘速覽

Organization 是公司在 Atlassian Cloud 的管理單位

  1. Organization 是什麼Organization 把公司的使用者與 app 集中在一個地方管理。Org admin 管員工的 Atlassian 帳號，也管屬於這個 organization 的 app。
  2. Organization、site、app 三層一個 organization 底下可以有多個 site；site 有自己的網址（名稱.atlassian.net），上面掛 Jira、Confluence 等 app。
  3. 帳號不綁 app、也不綁 organizationAtlassian 帳號可以用不同 organization 的 app；要等你驗證網域並 claim 帳號，它才變成你們的 managed account。
  4. 兩種建立方式從 atlassian.com 註冊 app 時，會同時建立 site 與 organization；也可以到 admin.atlassian.com/o/create 建立沒有 app 的 organization。
  5. 建立者就是 org admin建立 organization 的人自動成為 org admin。官方建議至少要有兩位 org admin，以免唯一的帳號遺失或被盜。
  6. 刪除要先清空刪除 organization 前要取消所有訂閱、移除網域與 app、等過保留期；刪除後 15 天內可以請 support 還原。

  • What is an Atlassian organization?Users aren’t tied to one organization either until you can claim ownership of their accounts.
  • Create an Atlassian organizationWhen you sign up for one of these apps for the first time, you also create a site and organization for that app.

  • Can I restore an organization?If you need to restore an organization, contact Atlassian support within 15 days of deleting it.
結構

Organization、site、app 與使用者

層次是什麼考試要記的事
Organization公司的管理單位，集中管理使用者、app、安全設定與帳單從這裡可以看到所有管理設定與帳單資料
Site一個網址（名稱.atlassian.net），上面掛一個或多個 appOriginal 體驗的文件寫明：每個 app instance 都屬於一個 site，site 有自己的 URL 與管理設定
App（舊稱 product）Jira、Jira Service Management、Confluence、Statuspage、Trello、Opsgenie、Bitbucket 等Free、Standard、Premium 方案每個訂閱只含一個 app instance
Atlassian account使用者本人的帳號，不綁 app，也不綁 organization驗證網域並 claim 之後才是 managed account，由 org admin 管

這張表最該記的是最後一列：使用者帳號和 organization 是分開的。同一個人可以同時使用你們與別家公司 organization 的 app；你能完整控制的只有 claim 之後的 managed account。

兩種 user management 體驗

官方文件常分成 centralized 與 original 兩種 user management。分辨方法是看 Users 頁在哪裡：在 organization 的 Directory 底下是 centralized；在 Apps 裡某個 site 底下是 original。Centralized 只有一份使用者目錄，所有 site 共用；original 是每個 site 各自管理自己的使用者與 group。

自我檢查：先在心裡回答，再點開對答案
Q1Leo 用個人 Gmail 帳號參與兩家公司的 Jira，這兩家公司都能把 Leo 的帳號刪掉嗎？看答案
不能。Leo 的帳號不屬於任何一家公司的 organization（沒有被 claim），對兩家公司來說都是 external user；它們只能移除 Leo 在自己 organization 的存取。
本段必考
  • Organization → site → app；帳號不綁 app、也不綁 organization。
  • Users 在 Directory 底下＝centralized；在 site 底下＝original。

建立

建立 organization、site 與 app

  1. 註冊一個 app到 www.atlassian.com，選想試用的 app，按 Try cloud 或 Try now。過程中可能會問你要不要再加選其他 app。
  2. 輸入 email輸入要用來登入的 email。已經有 Atlassian 帳號就用那個 email；沒有的話會帶你建立帳號。
  3. 取 site 名稱如果你的帳號已經能用其他同種 app，會先列出來，提醒你可能是要登入既有的站。要新建就選 start a new site，再輸入 site 名稱；這個名稱會變成網址的子網域。
  4. 完成設定照提示完成 app 設定。這一步同時建立了 site 與 organization，你就是 org admin，可以到 Atlassian Administration 邀請使用者。
註冊時的選擇或預設結果
是否加選其他 app註冊流程可能詢問要不要加選；選了通常會一起建在這個新 site 上（推論）
Site 名稱變成網址的子網域，例如 labjira.atlassian.net
App 角色的 default group每加一個 app，系統就為它的每個 app 角色建立一個 default group
從 Atlassian Administration 加 app以 Standard 或 Premium 試用開始；官方 Add app 頁寫試用結束時沒有付款資料就改成 Free 方案（超過 10 人的情況見 520.1.2）

考試的「建立時的預設與選項」多半就考這張表：site 名稱決定網址、app 一加進來就有 default group、新 app 從試用開始。

多個 organization

一間公司有好幾個 organization 時

  • 怎麼會有好幾個：公司改組、併購別家公司、各團隊自己註冊 app，或註冊新 app 時沒有加到既有的 organization，都可能多出 organization。
  • 切換：一個人可以是多個 organization 的 admin；進 Atlassian Administration 時先選 organization，所有設定都只作用在選到的那一個。
  • 合併的作法：把一個 organization 的所有 app 轉移到另一個，再刪掉不要的那個。官方頁先寫來源或目的地有多個 site 時不能自己合併（Enterprise 方案視為多個 site），同一頁稍後又寫 original user management 的多 site organization 可以自己轉移 app；centralized 的情況要找 support 協助。有試用或訂閱過 Atlassian Guard Premium、或 app 屬於 Atlassian Collection，也不能自己處理，要找 support。
  • 合併的好處：所有已驗證網域的使用者、所有 app instance 與所有帳單都在同一處管理；user provisioning 也能一次涵蓋所有 app。
  • 保持分開的理由：合併等於讓同一批 org admin 管理所有 app instance 與相關的人。若要讓兩群使用者與資料完全隔離，就保持分開。
  • Guard 帳單：管理多個 organization、多個 site 時，官方建議把所有 site 連到同一個 organization，Guard Standard 的計費人數才會正確。
由 support 執行的合併（consolidation）

官方的 consolidation 指南寫明：來源 organization 的 org admin 會變成目的地的 org admin；同名 group 會在來源端被改名；整個過程不能復原，合併後無法再拆回兩個 organization。

本段必考
  • 合併＝轉移所有 app，再刪掉不要的 organization；多 site 不能自己合併。
  • 要讓兩群人完全隔離 → 保持兩個 organization。
資料來源（7）有疑慮時點開看官方原文

  • Can I merge my Atlassian organizations?This is done by transferring all apps from one organization to another. After the transfer, the unwanted organization is deleted.
  • Can I merge my Atlassian organizations?If you have an Enterprise plan, your organization is considered to have multiple sites.
  • Can I merge my Atlassian organizations?If either the source or destination organization has multiple sites, you can transfer the app instances by yourself.
  • Can I merge my Atlassian organizations?When you merge organizations you’re essentially allowing one group of administrators to manage all app instances, and everything relating to the people who use them.

刪除

刪除 organization 與還原

  1. 先備份官方建議先備份要保留的資料。
  2. 取消訂閱取消 organization 內每個 site 的所有 app 訂閱。Rovo、Atlassian Guard 這類 app 不能直接取消，要聯絡 support 移除。
  3. 移除網域與 app把所有 domain 與 app 從 organization 移除。
  4. 等保留期等過各 app 或 site 的保留期（通常 14 到 60 天）。Improved billing 體驗在 app 停用後還要再等 60 天。
  5. 刪除確認相關 site 都已永久刪除，再到 Organization settings → Profile → Delete organization。只有 org admin 能做；所有 admin 都會收到 email 通知。
項目說明
一起被刪掉的Admin API tokens、authentication 與 organization policies、audit log、access settings、organization metadata、identity 與 lifecycle 資料
還原期限刪除後 15 天內聯絡 Atlassian support
還原到哪裡只回到刪除當下的狀態；刪除前已移除的網域、app 等都不會回來

還原只會拿回一個「空殼」organization。所以考題問「刪錯了怎麼辦」時，答案是 15 天內找 support，而且拿不回刪除前就移除的 app。

本段必考
  • 刪 organization 前：取消訂閱 → 移除網域與 app → 等保留期。
  • 15 天內可請 support 還原，只回到刪除當下的空殼。

第一次做 Lab？先看 Lab 環境準備：用測試站台、準備測試帳號。畫面名稱可能隨 Atlassian 更新而不同，以下以現行畫面為準。

目標：在 Atlassian Administration 找出 organization、site、app 與使用者目錄各在哪裡，並親手改一次 organization 名稱。

這個 Lab 對應的考點

準備

步驟

  1. 你應該看到：看到 organization 的摘要（月活躍使用者、存取申請、帳號安全等）；新 organization 的資料通常不多。
  2. 你應該看到：有的話就是 centralized user management；Users 裡有你、Leo、Kim。
  3. 你應該看到：只有 labjira 一個 site；Jira 與 Confluence 都掛在這個 site 上。
  4. 你應該看到：通常會看到 jira-users-labjira、confluence-users-labjira、jira-admins-labjira 這類 default group，以及 org-admins（或 site-admins）。這些是加 app 時自動建立的。
  5. 你應該看到：右上角或 organization 選單的名稱跟著變了。網址裡 /o/ 後面那串 ID 通常不會變：改名不改 org ID。
  6. 你應該看到：Jira 與 Confluence 各是一個訂閱，都是 Free。
  7. 你應該看到：知道刪除入口在這裡；還有 app 與訂閱時不能直接刪。

Organization、site、app 與使用者
  • Organization → site → app；帳號不綁 app、也不綁 organization。
  • Users 在 Directory 底下＝centralized；在 site 底下＝original。
建立 organization、site 與 app
  • 註冊 app＝同時建立 site 與 organization；site 名稱＝子網域。
  • 沒有 app 的 organization：admin.atlassian.com/o/create。
Atlassian Administration 的各區
  • 改 organization 名稱：Settings → Details；org ID 不變。
  • Directory 管人、Apps 管 app、Billing 管帳單。
一間公司有好幾個 organization 時
  • 合併＝轉移所有 app，再刪掉不要的 organization；多 site 不能自己合併。
  • 要讓兩群人完全隔離 → 保持兩個 organization。
刪除 organization 與還原
  • 刪 organization 前：取消訂閱 → 移除網域與 app → 等保留期。
  • 15 天內可請 support 還原，只回到刪除當下的空殼。
