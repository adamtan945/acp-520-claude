# ACP-520 繁體中文教材

Atlassian **ACP-520 Atlassian Cloud Organization Admin** 認證的完整中文教材：15 節逐節講解 + 150 題題庫（單選、多選、圖例題）+ 45 題計時模擬考。

線上閱讀：<https://adamtan945.github.io/acp-520-claude/>

## 內容

- **15 節**對應官方 Exam Topics（2026/4 改版）：每節都是「3 分鐘速覽 → 圖解 → 分段講解（自我檢查、本段必考、資料來源）→ 易錯觀念 → 動手做 Lab → 一分鐘腦內整理 → 本節練習」。
- **動手做 Lab**：每節一個，在自己的測試站台照步驟操作、故意改一個設定再觀察，留下畫面記憶；共用的測試站台、帳號與 project 見「Lab 環境準備」頁。
- **150 題題庫**：英文題幹（貼近實考）＋中文翻譯，每個選項都有解析與官方來源；可錯題重練、全真 45 題模擬考（90 分鐘、答對 33 題及格）。紀錄存在瀏覽器，可匯出匯入。
- **考前速讀**、**易錯與易混**、**圖鑑**：由各節內容自動彙整。
- 手機、平板、桌機都能閱讀；淺色與深色模式。

## 關於內容正確性

- 官方文件近年改用新名稱：product 改稱 app、Atlassian Access 改為 Atlassian Guard、project 改稱 space。考試與舊文件的說法並陳。
- 每一節都依考綱指定或對應的 Atlassian 官方文件撰寫；官方文件改版與考綱不同之處兩版並陳。
- **每一段都附資料來源**：官方原文一句，加上直接捲到該句的連結（text fragment）；建置時逐句和官方文件存檔核對。找不到官方原文的主張會在來源框明確標示「找不到官方原文」。
