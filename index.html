520.1 Atlassian 組織（25%）：官方考綱原文3 節

520.1.1 Organization 的結構與建立

  • Administer users and groups across multiple Cloud organizations, sites, and products跨多個雲端 organization、site 與 app 管理使用者與 group（本節談組織層級的部分）
  • Org admins must be able to create, navigate, and administer organizations with multiple sites and products（舊版 domain 說明）Org admin 要能建立、導覽並管理有多個 site 與 app 的 organization
  • Understand the purpose and structure of an Atlassian organization了解 Atlassian organization 的用途與結構
  • Create a new organization, site, and product建立新的 organization、site 與 app
  • Identify default and optional configurations based on selections made during signup依註冊時的選擇，辨認預設與選用的設定

520.1.2 Subscriptions 與 billing

  • Manage subscriptions and billing管理訂閱與帳單
  • Understand how to view, switch, and cancel product subscription plans了解怎麼查看、切換與取消 app 的訂閱方案
  • Understand how billable users are calculated了解計費使用者怎麼計算
  • Understand how to manage your bill了解怎麼管理帳單

520.1.3 Admin 角色與委派

  • Delegate admin privileges to other org admins and product admins把 admin 權限委派給其他 org admin 與 app admin
  • Recall the following five admin roles: org admins, Jira product admins, Jira project admins, Confluence product admins, and Confluence space admins記住五種 admin：org admin、Jira app admin、Jira project admin、Confluence app admin、Confluence space admin
  • Understand and distinguish between the roles based on the product features they use and the tasks they perform依使用的功能與執行的工作，分辨各種角色
  • Grant and revoke the org admin role授予與收回 org admin 角色
  • Grant and revoke the product admin role for Jira Administration and Confluence授予與收回 Jira Administration 與 Confluence 的 app admin 角色

520.3 使用者管理與存取控制（34%）：官方考綱原文5 節

520.3.1 使用者如何取得存取

  • Configure user access settings, including approved domains and user invites設定使用者存取設定，包含 approved domains 與 user invites（新版能力清單）
  • Manage product access for both non-managed and managed accounts管理 non-managed 與 managed 帳號的 app 存取（新版能力清單）
  • Administer users and groups across multiple Cloud organizations, sites, and products跨多個 organization、site、app 管理使用者與 group（新版能力清單）
  • Understand the available methods to grant product access了解給予 app 存取的各種方式（舊版 1.3）
  • Understand the site access settings that control how users get access to your site了解控制使用者如何取得 site 存取的設定（舊版 1.3）
  • Configure approved domains / invitation links / user invites設定 approved domains、invitation links、user invites（舊版 1.3）

520.3.2 Access requests

  • Manage product access for both non-managed and managed accounts管理 non-managed 與 managed 帳號的 app 存取（新版能力清單）
  • Understand when users request access了解使用者何時會申請存取（舊版 1.4）
  • Product access requests must be made by a user with a verified email address and Atlassian account申請者要有已驗證 email 與 Atlassian account（舊版 1.4）
  • You can approve or deny these requests on the Access requests page在 Access requests 頁核准或拒絕（舊版 1.4）
  • When you grant a user access to a product, they’re added to the default group for that product group (which may be the default group for other products, as well) and billing starts for the new user核准後使用者會被加進 default group（可能同時是其他 app 的 default group），並開始計費（舊版 1.4）
  • A user who has requested access and been denied won’t be able to request access again.被拒絕的人不能再申請（舊版 1.4）

520.3.3 管理使用者

  • Manage product access for both non-managed and managed accounts管理 non-managed 與 managed 帳號的 app 存取（新版能力清單）
  • Administer users and groups across multiple Cloud organizations, sites, and products跨多個 organization、site、app 管理使用者與 group（新版能力清單）
  • Understand managed and non-managed accounts了解 managed 與 non-managed 帳號（舊版 2.1）
  • Grant access to products via product roles用 app 角色給予存取（舊版 2.1）
  • Prompt reset password提示使用者重設密碼（舊版 2.1）
  • Suspend and restore access / Remove user / Log in as user暫停與恢復存取、移除使用者、以使用者身分登入（舊版 2.1）

520.3.4 Groups

  • Administer users and groups across multiple Cloud organizations, sites, and products跨多個 organization、site、app 管理使用者與 group（新版能力清單）
  • Understand the impact of changes to groups in Jira and Confluence了解 group 變更對 Jira 與 Confluence 的影響（新版能力清單）
  • Define default product access groups定義 default app access group（舊版 2.3）
  • Understand the configuration choices for default access groups / Rules for default access groupsDefault group 的設定選擇與規則（舊版 2.3）
  • Purpose and rules for site-admins groupsite-admins group 的用途與規則（舊版 2.3）
  • Create and update groups建立與更新 group（舊版 2.3）

520.3.5 變更的影響與排查

  • Understand the impact of changes to groups in Jira and Confluence了解 group 變更對 Jira 與 Confluence 的影響（新版能力清單）
  • Administer users and groups across multiple Cloud organizations, sites, and products跨多個 organization、site、app 管理使用者與 group（新版能力清單）
  • Understand the impact to an organization’s products when various directory changes are made了解各種目錄變更對 organization 內 app 的影響（舊版 2.4）
  • Delete groups / Suspend access, restore access, remove user / Deactivate and delete managed accounts刪 group；暫停、恢復、移除使用者；停用與刪除 managed account（舊版 2.4）
  • Analyze and troubleshoot the impact of user and group changes within Jira family of products and within Confluence分析並排查使用者與 group 變更在 Jira 系列與 Confluence 的影響（舊版 2.4）
520.4 Atlassian Guard 與進階管理（16%）：官方考綱原文4 節

520.4.1 Managed accounts 與網域驗證

  • Manage product access for both non-managed and managed accounts（新版能力清單）管理 non-managed 與 managed 帳號的 app 存取
  • Understand what managed accounts are: Some or all of the Atlassian accounts with email addresses from your verified domain(s)了解 managed account：已驗證網域底下 email 的部分或全部 Atlassian 帳號
  • Managed accounts give you the most security and access control over a company's use of Atlassian productsManaged account 讓公司對 Atlassian 產品的使用有最大的安全與存取控制
  • Verify a domain either through HTTPS or DNS TXT用 HTTPS 或 DNS TXT 驗證網域
  • Understand where to access them under Directory > Managed accounts知道在 Directory > Managed accounts 找到它們
  • Understand rules for managed and un-managed accounts了解 managed 與 un-managed 帳號的規則
  • View a managed user account / Edit a managed account / Deactivate a managed account / Delete a managed account檢視、編輯、停用、刪除 managed account

520.4.2 Atlassian Guard

  • (Domain 4, 2026) Atlassian Guard & advanced administration新版 domain 4 名稱：Atlassian Guard 與進階管理
  • Understand what is Atlassian Access (included in the Enterprise plan or purchased as a subscription on other plans)了解 Atlassian Access（現名 Atlassian Guard）：Enterprise 方案已內含，其他方案另外訂閱
  • Understand that you can connect your identity provider to your Atlassian organization for single sign-on, user sync, and provisioning了解可以把 identity provider 接到 organization，做 SSO、使用者同步與 provisioning
  • Understand how Shadow IT sites are created了解 Shadow IT site 是怎麼產生的
  • Understand how to revoke a user's API tokens了解怎麼撤銷使用者的 API token
  • Use admin insights使用 admin insights

520.4.3 IP allowlist 與 data residency

  • Configure release tracks, sandboxes, IP allowlisting, admin APIs, and application tunnels（新版能力清單）設定 release tracks、sandboxes、IP allowlisting、admin APIs 與 application tunnels
  • Configure IP allowlisting設定 IP allowlisting（舊版 4.2 Configure Premium features）
  • View and manage data residency檢視與管理 data residency（舊版 4.3）

520.4.4 Admin APIs、application tunnels 與 custom email

  • Configure release tracks, sandboxes, IP allowlisting, admin APIs, and application tunnels（新版能力清單）設定 release tracks、sandboxes、IP allowlisting、admin APIs 與 application tunnels
  • Understand that you can manage your Atlassian cloud organization via the admin APIs / Create an API key / Revoke an API key了解可以用 admin APIs 管理 organization；建立與撤銷 API key
  • Understand what application tunnels are: Provide a secure pathway between a cloud organization and DC/Server instances that live on the company network了解 application tunnels：在 cloud organization 與公司網路內的 DC/Server 之間提供安全通道
  • Used to integrate products through application links that would otherwise require allowing incoming connections to the company network用來透過 application link 整合產品，否則就得允許外部連入公司網路
  • Allow integration of Atlassian products and exchange of data and functionalities in a secure way, without exposing the company network or allowlisting incoming connections or IPs安全地整合與交換資料，不必暴露公司網路，也不必把連入的連線或 IP 加進白名單
  • Add custom email addresses for product notifications / Understand the purpose of adding a custom email address為產品通知加入自訂 email 地址，並了解目的（舊版 4.1）

怎麼用

每一節都是同一個讀法

  1. 3 分鐘速覽先讀編號重點，知道這一節考什麼。
  2. 看圖流程圖、關係圖、設定畫面示意。沒實際操作過的功能，看畫面示意就知道設定在哪。
  3. 易錯觀念紅色 ✗ 是考題愛用的錯誤說法，綠色 ✓ 是正解。
  4. 資料來源每一段最後都有「資料來源」，展開就看到官方原文那一句；點連結會開官方頁面並直接捲到那一句。有疑慮時以官方原文為準。
  5. 動手做 Lab在自己的測試站台照步驟點一次、故意改壞一個設定再觀察，留下畫面記憶。第一次做先看 Lab 環境準備。
  6. 一分鐘腦內整理每段的「本段必考」收成一張大綱，讀完用它回想。
  7. 本節練習英文題幹貼近實考，按「中文」看翻譯；每個選項都有解析。每次作答都會記錄，看不懂按星號「不懂」。
